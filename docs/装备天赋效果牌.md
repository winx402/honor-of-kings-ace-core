# 装备、天赋与效果牌

完整覆盖主目录73件装备、258项天赋、98张效果牌的效果说明。装备、持续天赋与使用后结算的效果牌分开；所需阵营、英雄、阶段、解锁、唯一限制和动态参数以详细条目为准。平衡版本未统一指定。

## 天赋

- **兵行诡招**：选择后棋手生命减少10；开战给每名己方英雄2临时等级。每获胜一场，棋手生命恢复1，后续临时等级加成再增加1。
- **里程碑**：棋手达到5级，奖励6能量及装备箱1张。
- **三分新援**：立即得2能量，再随机获得一张二至三阶三分英雄牌。
- **整装待发**：若本回合完全没有打出英雄牌，下一回合开始奖励2能量。
- **先苦后甜**：选择此天赋之后累计输掉两场战斗，奖励6棋手经验。是否可反复触发未载。
- **防御领域**：棋手每次受伤少受2点；伤害最低值未另给定。
- **日落海新援**：立即得2能量，再随机获得一张二至三阶日落海英雄牌。
- **存款利息**：先获3能量；每回合结束，按当时每7能量再奖励1能量，余数和利息上限未载。
- **大河新援**：立即得2能量，再随机获得一张二至三阶大河流域英雄牌。
- **破格**：回合开始的商店自动刷新，会出现一张高一品阶英雄牌；高阶相对基准需结合商店品阶规则。
- **逐鹿新援**：立即得2能量，再随机获得一张二至三阶逐鹿英雄牌。
- **二象性**：获得二象坍缩天赋牌1张；使用时随机启用一种取得英雄牌的效果，具体分支由二象坍缩关联定义说明。
- **河洛新援**：立即得2能量，再随机获得一张二至三阶河洛英雄牌。
- **预言家**：分别获得胜利预言、失败预言各1张；用牌预测战斗结果，猜对才获对应奖励，奖励类别见两张关联牌。
- **三十而立**：备战阶段英雄总等级达到30，获得6棋手经验；总等级的统计区域未另标明。
- **好聚好散**：得到体面离场天赋牌1张。其移除指定英雄后，根据该英雄觉醒进度0、1、2、3分别奖励3、5、7、9能量。
- **瓶中人**：得到契约瓶天赋牌1张；获胜往瓶中累积3张随机英雄牌，失败损失已累积牌的一半，奇数取整未载。
- **狂铁·强化**：每次狂铁触发卡牌效果，狂铁自身攻速增加10%；增益期限与叠加上限未另给出。
- **战争头牌**：每回合取得一个品阶数字；本回合打出对应品阶英雄牌，额外提升4等级。数字抽取范围未载。
- **节能商店**：每次手动刷新之后，商店总有一张牌的能量购买费用减少1；哪张牌及费用下限未载。
- **随机成长**：每次开战给己方品阶最高的一名英雄永久+4等级；同阶并列如何选取未载。
- **微弱优势**：每名英雄首次打出觉醒牌时获22%暴击率与双吸血各11%；同英雄不能重复取得此增益。
- **双人游**：随机得到两张二至三阶英雄牌。
- **加速成长**：得到加速成长天赋牌2张；每张可指定一名英雄增加5等级。
- **刻舟减蓝**：英雄达到20级后，法力上限减少10；最低上限未载。
- **猪猪**：开战随机两名敌方英雄变猪，持续3秒。
- **专注射击**：开战赋予己方后两排英雄普攻成长：每次普攻攻速+3%、物攻+3，最多10层。
