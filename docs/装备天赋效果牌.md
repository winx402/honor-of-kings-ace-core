# 装备、天赋与效果牌

装备、持续天赋与使用后结算的效果牌是不同对象。本页只展示已有详细效果的条目；目录中其他条目仍保留分类、解锁条件及关联。具体平衡版本未指定。

## 装备

- **风暴巨剑**：基础材料；装备给英雄后可铸造1件输出装备。
- **圣者法典**：基础材料；装备给英雄后可铸造1件法术装备。
- **雷鸣刃**：基础材料；装备后可铸造输出装备1件。
- **守护者之铠**：基础材料；装备后可铸造防御装备1件。
- **力量腰带**：基础材料；装备后可铸造防御装备1件。
- **破碎圣杯**：基础材料；装备后可铸造功能装备1件。
- **速击之枪**：基础材料；装备后可铸造输出装备1件。
- **大棒**：基础材料；装备后可铸造输出装备1件。
- **魔女斗篷**：法防增加30；开战生成等于等级×5的法术护盾。
- **极寒风暴**：受普攻使攻击者攻速降低20%、2秒；同一目标攻击5次，远程冻结1秒，近战0.5秒。
- **御灵之纱**：开战护盾值=等级×15；盾破眩晕周围1格敌人1秒，破盾者眩晕2秒。
- **生命魔典**：受伤治疗自身及周围1格己方单位各5%最大生命，触发间隔2秒。
- **炽热支配者**：首次被控制获得300护盾与15秒免控；压制仍有效。
- **贤者之书**：法力上限降低10；每次施法增加相当于20%基础法攻，累计不超过6层。
- **铸梦·逐风**：开战及此后每8秒触发连续4次快速普攻。
- **无尽巨剑**：增加30%暴击率、60%暴击效果；暴击效果不叠加。
- **制裁之剑**：伤害给敌人施加10秒治疗及护盾削弱，普通伤害削弱30%，普攻伤害削弱70%，不叠加。
- **纯净苍穹**：每2秒法攻提高10并清除负面状态。
- **魔律之刃**：施法重复一次概率35%，每7级额外增加1个百分点。
- **虚无法杖**：法防穿透提高15点。
- **寒霜侵袭**：普攻施加5秒15%减速，最多5层；满层使其所受伤害提高20%、5秒，冷却10秒。
- **自然法杖**：法攻提高20%；每消耗远程40或近战80法力，随机敌人变猪2秒。
- **金色圣剑**：增加攻速30%+0.15×法攻%；普攻追加法伤20+0.3×法攻。
- **红魔**：周边1格无队友时伤害加成25%；每受3%最大生命伤害再加1%，加成上限100%。
- **影牙**：攻速增加50%。
- **破晓**：普攻削物防3，持续5秒；目标物防首次到0时追加其15%最大生命物伤。
- **凝渊**：暴击率增加20%；每次受击另加1%，达到100%暴击率再加100%移速。
- **日渊**：仅远程生效；普攻额外向生命最低的2敌射箭，各造成0.45×物攻。
- **名刀·司命**：第一次致死伤害触发1.5秒无敌和不可选中。
- **痛苦面具**：单次法伤超过目标最大生命8%时点燃3秒，每秒真实伤害=0.75×法攻。
- **法源之杯**：每秒法力恢复5。
- **破茧之衣**：开战法力加15，随机眩晕敌方等级最高3英雄之一；持续1秒+目标每10级0.5秒，最多5秒。
- **聚灵水晶**：受击额外恢复10法力，累计100后治疗自身20%最大生命。
- **冥王**：周围1格每名敌人提供物防10、基础物攻15%。
- **霸者重铠**：生命高于70%时减伤40%。
- **不死鸟之眼**：基础生命增加15%；治疗与护盾增加30%。
- **反伤重甲**：返还所受伤害的30%给伤害来源，返还为真实伤害。
- **红莲炎甲**：每2秒向1格周边敌人造成法伤20+5%自身最大生命；使其治疗及吸血降低50%、3秒。
- **近卫荣耀**：开战给1格范围己方单位双抗10；自身20，不可叠加。
- **不祥征兆**：前15秒减普攻伤害50%；攻击者攻速≥1.5时减70%。

## 天赋

- **兵行诡招**：获得时棋手扣10生命；开战全英雄临时等级加2。胜利恢复1棋手生命，临时等级加成再增长1。
- **里程碑**：棋手达到5级获能量6及装备箱1张。
- **三分新援**：能量增加2，随机获得三分2或3阶英雄1张。
- **整装待发**：若本回合未使用英雄牌，下回合开始额外获能量2。
- **先苦后甜**：取此天赋之后输2场，棋手经验奖励6。
- **防御领域**：每次棋手受伤少2点。
- **存款利息**：立即获能量3；每回合结束每存7能量增加1能量。
- **大河新援**：获得2能量和随机一张2—3阶大河流域英雄牌。
- **破格**：每回合自动商店刷新含1个高一阶英雄。
- **二象性**：获得二象坍缩1张；其随机触发一种获取英雄牌的效果。
- **三十而立**：备战中英雄等级合计达到30时奖励棋手经验6。
- **好聚好散**：获得体面离场1张；移除英雄时按觉醒进度0/1/2/3奖励能量3/5/7/9。
- **战争头牌**：每回合选出1个品阶数字；当回合打出该品阶英雄额外等级加4。
- **节能商店**：手动刷新后总有1张卡降价1能量。
- **随机成长**：开战时最高品阶英雄中1名永久等级加4。
- **微弱优势**：打出觉醒英雄牌时，该英雄增加22%暴击率和11%物理、法术吸血，每名英雄仅一次。
- **加速成长**：获得2张加速成长，每张可给指定英雄增加5等级。
- **银算盘**：卖出场上英雄，随机另一英雄等级加2。
- **五福临门**：获得同名天赋牌1张，可随机获取5张英雄。
- **小电池包**：立即补充5能量。
- **复印机**：获得两张天赋牌复印机，可指定1—3阶英雄获得其英雄牌。
- **扩编名额**：可买2次人口，每次支付8能量、人口上限加1。
- **消费返利**：累计消费每15能量奖励加速成长1张，可给目标增加5等级。
- **金算盘**：卖出场上英雄使随机英雄等级加3。
- **电池包**：立即补充8能量。
- **人才市场**：奖励人才搜寻3张。
- **同路人**：同回合每出4张同阵营英雄，随机奖励该阵营1张英雄。
- **重装上阵**：开战时装备至少2件的英雄获得15%增伤及15%减伤。
- **抢攻**：立即获得普通装备1张；后续5回合累计对棋手伤害20则奖励10能量。
- **超速成长**：获得1张指定英雄增加15等级的天赋牌。
- **王牌认证**：开战若有至少3个4至5阶英雄，获2至3阶效果锦囊1张。
- **前浪的荣光**：获得2张同名天赋牌，各将指定英雄后奖励同阵营高1至2阶英雄1张。
- **全军列阵**：指定1名英雄后召唤同阵营单位补满人口，但品阶不超过商店可购上限。
- **小身体大能量**：开战英雄体型缩小、攻速加60%、暴击率加40%、最大生命减20%。
- **瞬影连斩**：闪现英雄击败敌方单位时，立即闪现至最近敌人处，并无敌0.5秒。
- **智能装甲**：随机获得一件日落海专属装备；英雄每穿戴一件该类装备，其整备额外触发一次。
- **最终守卫**：最后一名河洛英雄受到致命伤害时获得无敌和50%攻速，初始持续1秒；本场英雄每触发过一次牺牲，无敌时间增加0.25秒，攻速增益仍为1秒。
- **乐善好施**：己方英雄触发登场时，随机两名三分英雄各增加2级。
- **挂帅上阵**：获得一张挂帅牌：令指定三分英雄的等级等同于最近一名三分英雄。
- **令行如流**：获得一张战术牌，此后每个回合开始再获一张；棋手达到5级后必定为高阶战术。
- **春风化雨**：回合开始获得一张上阵逐鹿英雄的同名牌；上一轮获胜时改为两张。
- **始祖熊灵**：奖励不占人口的大河单位始祖熊灵；开战单位数量每比敌人多1，其永久等级加2。
- **身外身**：获得孙悟空1张；悟空施法叫出2化身各攻击1次，每胜利化身数量永久加1。
- **逐星**：获得李白与曜各1张；二者共战，李白施法让曜模仿，3次后形成融合技能，具体融合招式待补。
- **宝盒**：获得露娜与悟空各1张；共战时一方致死退场6秒，若另一方期间仍活则满生命满法力返回。
- **能量汲取**：出售上阵英雄时，把其等级提供给阿科米亚核心。
- **强者恒强**：开战觉醒英雄双攻各加50；全体觉醒时额外双吸血20%。
- **泉水**：每回合开始棋手治疗3；满生命时改获经验4。

## 效果牌

- **吸纳人才**：从4张候选英雄中选择1张。
- **1阶英雄兑换券**：从3张一阶英雄候选中选择1张。
- **研读会**：棋手经验增加3。
- **高级人才**：随机英雄1张，品阶=棋手等级+1；超出5阶的边界未知。
- **援护战术**：转瞬；逐鹿英雄本回合护盾=50+25×已使用战术数量。展示当前75为状态值。
- **古币**：转瞬；指定河洛英雄等级增加2。
- **惊喜补贴**：获得免费刷新3次。
- **跳级**：指定英雄从核心夺取等级，单次最多5。
- **图腾仪式**：随机获得1张与图腾有关的大河英雄。
- **古币多多**：获得古币2张。
- **弦音**：指定1至3阶英雄觉醒进度增加1。
- **2阶英雄兑换券**：从3张二阶英雄候选中选择1张。
- **临阵磨枪**：立即触发指定英雄的整备。
- **唤醒**：立即触发指定英雄的登场。
- **演练战术**：转瞬；全体英雄等级增加1。
- **推演战术**：转瞬；指定逐鹿英雄本回合降低法力上限，基础值5、累积增强上限20；占位符动态显示规则待核实。
- **特训战术**：转瞬；指定英雄等级增加4。
- **招募战术**：转瞬；随机奖励逐鹿英雄1张。
- **简易协作**：指定英雄加3等级，随机英雄另加2。
- **精致古币**：转瞬；指定河洛英雄等级增加4。
- **无阵营征召令**：获得无阵营英雄2张。
- **精密协作**：指定英雄加4等级，随机英雄另加3。
- **经典研读会**：棋手经验增加4。
- **遗志**：移除指定英雄，把其永久等级转给随机一名己方英雄；临时等级不转移。
- **广纳良才**：从5张英雄候选中选择2张。
- **换帅**：指定三分英雄与距其最近的三分英雄互换等级。
- **照影**：随机获取场上1名英雄对应的牌。
- **助力核心**：核心加2等级；场上每名日落海英雄再重复一次。
- **超级补贴**：获得免费刷新4次。
- **武装分解**：毁掉目标所有装备；毁1/2/3件分别奖励能量4/妙音1张/珍品宝箱1张。
- **集体唤醒**：所有英雄的登场各触发一次。
- **化铁为金**：指定1—3阶英雄，随机变为当前不在场的五阶英雄，觉醒并保留当前等级（包括临时等级）；不能指定结果，不能获得四阶李信。
