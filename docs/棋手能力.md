# 棋手能力

20名棋手的技能、秘技、专属及关联分支。棋手不是同名英雄；以下能力适用万象规则体系，不直接用于取消棋手能力的模式。所有动态费用、目标、阶段及有效期仍按具体条目。

## 小妲己

主技能为被动。被动技能不按主动消费调用。

**技能：怦然心动**。购买卡牌累计每满4张：随机补入1张效果牌。

**秘技：心动节拍**。怦然心动触发达到任务阶段：阶段触发数为5、4、3，各取得1张心之引力；是否阶段重新计数未明确。

**专属：魅力无限**。每回合打出首张效果牌：总共结算2次效果。

**关联分支与奖励**：

- **怦然心动**：购买卡牌累计每满4张：随机补入1张效果牌。
- **心动节拍**：怦然心动触发达到任务阶段：阶段触发数为5、4、3，各取得1张心之引力；是否阶段重新计数未明确。
- **心之引力**：使用：增加4次临时刷新；这4次刷新对应商店的购买能量费用各减1。
- **魅力无限**：每回合打出首张效果牌：总共结算2次效果。

未指定：心动节拍5/4/3阶段重新计数规则。

## 瑶妹

主技能为被动。被动技能不按主动消费调用。

**技能：可爱小鹿**。比赛开局；每回合成长：开局召唤小鹿；每回合加2级，若上一场获胜则另加4级。

**秘技：超绝可爱小鹿**。每经过3回合：获得1张神奇小鹿秘技牌。

**专属：巨型玩偶**。专属天赋生效：增加30级，同时取得1件小鹿的庇护。

**关联分支与奖励**：

- **巨型玩偶**：专属天赋生效：增加30级，同时取得1件小鹿的庇护。
- **可爱小鹿**：比赛开局；每回合成长：开局召唤小鹿；每回合加2级，若上一场获胜则另加4级。
- **超绝可爱小鹿**：每经过3回合：获得1张神奇小鹿秘技牌。
- **神奇小鹿·嘲讽**：使用；开战；开战后每3秒：使用时小鹿增加8级；开战后小鹿在敌人间无视碰撞移动；每3秒嘲讽周围1格敌人1次，周期事件不重复加等级。

- **神奇小鹿·双生**：战斗开始；本局累计胜利至少5次：在附近生成自身复制体；满足5胜条件另加12级；卡面当前0胜不是阈值。
- **神奇小鹿·共鸣**：使用：等级改为原值的2倍。
- **神奇小鹿·奉献**：小鹿死亡：将小鹿等级均分给己方英雄，所得为战斗结束清除的临时等级。

未指定：小鹿基础面板、初始等级、默认位置、人口与基础技能；小鹿战斗复制体的持续和等级继承细节。

## 阿离

**技能：枫叶舞**。主动指定；指定英雄承受最大生命20%的伤害：获得护盾并移动到纸伞所在位置；受伤是单次还是累计判定未明确。

**秘技：惊鸿游龙**。绑定英雄击败敌方英雄达到3、7、11、15：各奖励翩跹舞步1张，并各解锁1项枫叶舞特性，总计4项。

**专属：即刻起舞**。专属天赋使用：从3项中选择1项。

**关联分支与奖励**：

- **枫叶舞**：主动指定；指定英雄承受最大生命20%的伤害：获得护盾并移动到纸伞所在位置；受伤是单次还是累计判定未明确。
- **惊鸿游龙**：绑定英雄击败敌方英雄达到3、7、11、15：各奖励翩跹舞步1张，并各解锁1项枫叶舞特性，总计4项。

- **枫之洪流**：绑定英雄首次转移后：在转移后的3秒中可无限施放技能。
- **翩跹馈赠**：转移后普通攻击累计满15次：补充1次转移机会。
- **枫灵涌动**：转移后：连续4秒每秒恢复15法力。
- **红叶染锋**：绑定英雄离场：继承前任真实等级的一半，只允许继承1次。
- **有叶新生**：转移后：恢复最大生命20%。
- **枫佑永驻**：强化后：护盾数值增大且不再受持续时间限制；具体增幅缺失。
- **拈花一指**：转移后：造成2秒眩晕；附近范围未给格数。
- **红枫疾舞**：转移后：接下来的4次普攻以最大攻速完成；最大值未给出。
- **枫华之刃**：转移后：造成伤害提升25%；结束时间未给出。
- **枫影无拘**：转移后：获得5秒控制免疫。
- **枫舞扶摇**：每回合第一次转移：得到5加本局英雄击败数的临时等级；每个击败再贡献1级。

- **层林遮影**：转移后：7秒内不被敌人优先选作攻击对象。
- **一叶双生**：转移发生：留下最大生命为本体30%的不可攻击分身；生成时嘲讽周围敌人2秒，死亡时再眩晕周围敌人。

- **踏叶摘星**：强化后：再次转移所需的击败英雄数减少1。

## 玉环

主技能为被动。被动技能不按主动消费调用。

**技能：霓裳曲**。每打出3张非觉醒英雄牌：按这3张牌的相同性、品阶、阵营关系选指法并结算1次；多条件同时满足的优先级未明。

**秘技：自成曲调**。累计完成6次琵琶弹奏：获得惊鸿调1张，总奖励上限2张。

**专属：余音绕梁**。专属生效：新增3次惊鸿调演奏机会。

**关联分支与奖励**：

- **霓裳曲**：每打出3张非觉醒英雄牌：按这3张牌的相同性、品阶、阵营关系选指法并结算1次；多条件同时满足的优先级未明。
- **轮指**：3张相同非觉醒英雄牌形成组合：触发轮指，令下一次指法结算2次；这是组合判定版本。
- **扫拂**：3张同品阶非觉醒英雄牌形成组合：触发扫拂，各增加等于棋手等级的英雄等级；这是组合判定版本。
- **吟揉**：3张同阵营非觉醒英雄牌形成组合：触发吟揉，随机得1张转瞬英雄牌；这是组合判定版本。
- **自成曲调**：累计完成6次琵琶弹奏：获得惊鸿调1张，总奖励上限2张。
- **惊鸿调**：使用：按记录重放前6次指法并结算对应效果；剩余可得2张是状态值。
- **余音绕梁**：专属生效：新增3次惊鸿调演奏机会。
- **轮指**：轮指结算：下一次指法重复结算，共2次；这是独立效果版本而非三牌判定。
- **扫拂**：扫拂结算：分别增加棋手当前等级数的英雄等级；这是独立效果版本。
- **吟揉**：吟揉结算：随机得到1张转瞬英雄牌；这是独立效果版本。
- **绞弦**：绞弦结算：增加1级；组合触发条件未在此独立效果中列出。

未指定：三张同时同名、同阶、同阵营时各指法判定优先级；绞弦的组合条件。；轮指对惊鸿调重放及下次指法计数的具体交互。
