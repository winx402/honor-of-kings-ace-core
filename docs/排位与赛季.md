# 排位、组排与赛季规则

以下描述客户端规则集774472的排位与钻石赛季机制；当前生效状态未指定。它们不是一套已确认的当前完整计分参数。排位段位、赛季徽章储蓄与钻石盈利进度分别记录。

## 排位计分和保护

排位分由名次基础分与各类加成组成；完整名次分表、加成组合与取整仍未确定。赛季结束结算，新赛季段位折算继承，具体折算表未指定。

该规则集在最强王者1000、2000、3000分开启掉段保护，同时声明3000分以上不再享受掉段保护。两项的覆盖关系，以及保护对积分或段位的具体影响未确定，不能据此推定3001分必定保留3000分底线。

## 棋手选择与特邀

自由选择可使用已可用棋手；特邀模式给每名玩家随机三名候选。选择特邀或随机棋手参赛，开局增加特邀天赋；使用特邀棋手取得前三另有奖励。普通特邀的随机棋手是否同享结算奖励未指定。

星彩特邀在钻石段位开放并随段位提高出现概率，此时特邀天赋替换为星彩特邀天赋。选择特邀或随机棋手并取得前三，额外奖励为星彩秘宝。具体概率、候选与段位选择模式表未指定。

## 组排有分同享

启用后，队员得分与队伍中名次最高者的对局结算得分一致，不按队伍平均名次计算。最强王者以下组排可不限次数；含王者0—4999分玩家时，需要房间内玩家两两满足亲密度资格；含王者5000分及以上玩家时不可启用。

| 亲密度档位 | 王者积分条件表述 | 边界 |
| --- | --- | --- |
| 500 | 500分以下 | 恰好阈值是否包含未指定 |
| 1000 | 1000分以下 | 恰好阈值是否包含未指定 |
| 3000 | 3000分以下 | 恰好阈值是否包含未指定 |
| 5000 | 5000分以下 | 另有5000分及以上禁用规定；统一覆盖关系未指定 |

房主另可选择队伍或个人计分。该选择与低段位有分同享规则的优先关系、各房间范围及个人加成组合未确定。资格门槛不能补成未经定义的严格不等式。

## 赛季上分徽章

新赛季按上季结算段位获得储蓄分；排位取得前三后，从储蓄中领取额外加分，直至储蓄耗尽。储蓄不足单次奖励时的尾数处理未指定。

| 上季结算段位 | 储蓄分 |
| --- | --- |
| 秩序白银 | 100 |
| 荣耀黄金 | 200 |
| 尊贵铂金 | 300 |
| 永恒钻石 | 600 |
| 至尊星耀 | 1000 |
| 最强王者 | 1400 |
| 万象王者 | 1900 |

第一、二、三名每次分别领取50、40、30储蓄分作为额外加分；不能把储蓄初值当作每局自动加分。

## 夺冠阵容

星耀及以上玩家在万象排位夺冠后，可以保存本局阵容。取得更强力的阵容后主动保存，会替换原阵容；可与其他玩家的夺冠阵容切磋，并保留胜负记录。保存数量、强弱判定、完整保存内容以及切磋是否影响排位分未指定。

## 钻石阶段与周榜

钻石狂潮的七阶段以累计盈利推进，新赛季重置该模式段位和盈利进度。具体阶段门槛与盈利计算未指定。

钻石收益周榜统计玩法收益，系统产出不计入。每周一零点开始结算，随后随机重新分组；分组后参加玩法结算可上榜。时区、净值口径和分组规则未指定。
