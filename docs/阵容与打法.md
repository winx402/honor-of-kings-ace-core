# 阵容与打法

这五套入门模板涵盖登场、整备、图腾、古币和效果牌联动，适用于万象大赛规则体系。具体平衡版本未指定，不提供当前热门度、胜率或强度排名。英雄名单是成型目标，按容量逐步组装；装备是适配选择，天赋需实际获得并满足条件。

## 三分登场流

成型英雄：吕布、蔡文姬、赵云、貂蝉、小乔、周瑜、曹操。

曹操的整备重触三分登场；蔡文姬响应三分英雄牌，小乔响应登场，形成等级成长。吕布接替前期输出。

棋手选择：白歌、马可、常小娥。天赋方向：乐善好施、挂帅上阵。

- 1—3回合：孙尚香开局，缺牌用弈星或牛魔；第2回合升2级，找蔡文姬、曹操、赵云。
- 4—7回合：补貂蝉，升3级；优先觉醒曹操、蔡文姬，备换帅后升4级找小乔。
- 8—11回合：升5级找吕布、周瑜；先让吕布靠近孙尚香上阵，以换帅交换等级，再卖孙尚香补周瑜。
- 12回合后：需要保护吕布时，赵云可换太乙真人。

站位：以曹操承伤，吕布输出，小乔置后；周瑜可补防装与法源之杯。

调整：缺赵云、貂蝉、周瑜时，可暂用甄姬、阿轲等三分或登场英雄。换帅交换指定三分与最近三分的等级；遗志移除目标并把永久等级转给随机友军，应控制接收目标。

装备方向：吕布可选炽热支配者、无尽巨剑、红魔；曹操可选近卫荣耀、御灵之纱、不死鸟之眼。

天赋条件：乐善好施：己方英雄触发登场时，随机两名三分英雄各增加2级。；挂帅上阵：获得一张挂帅牌：令指定三分英雄的等级等同于最近一名三分英雄。

## 日落海整备流

成型英雄：安琪拉、朵莉亚、狂铁、亚连、米莱狄、雅典娜、海诺。

整备英雄提升阿科米亚核心，朵莉亚响应整备、海诺响应核心升级；雅典娜在开团时再触发整备。核心分配临时等级给日落海英雄。

棋手选择：香香、常小娥、闹闹。天赋方向：能量汲取、智能装甲。

- 1—3回合：优先狂铁，第2回合升2级。
- 4—7回合：升3级，补米莱狄、亚连，找朵莉亚和安琪拉并觉醒。
- 8—11回合：升5级补雅典娜、海诺，继续觉醒整备组件。
- 12回合后：有空位时，可用露娜触发整备。

站位：对手有闪现时，以友军围住安琪拉；雅典娜承担前排。

调整：决胜回合可只保留雅典娜和安琪拉或海诺，将核心分配集中；这是牺牲后续成长换取当前战力的选择。远洋宝藏可提供日落海装备。

装备方向：安琪拉可选法源之杯、虚无法杖、炽热支配者；雅典娜可选霸者重铠、近卫荣耀、不死鸟之眼。

天赋条件：能量汲取：出售上阵英雄时，把其等级提供给阿科米亚核心。；智能装甲：随机获得一件日落海专属装备；英雄每穿戴一件该类装备，其整备额外触发一次。

## 大河图腾流

成型英雄：敖隐、虞姬、张良、少司缘、鬼谷子、大司命、东皇太一。

三名召唤者提供三种图腾；虞姬按图腾数成长，张良响应开团。敖隐随图腾持续增加攻速与临时等级，东皇太一改变图腾受击优先级。

棋手选择：香香、瑶妹、常小娥。天赋方向：复印机、大河新援。

- 1—3回合：牛魔、干将莫邪过渡，第2回合升2级。
- 4—7回合：升3级找虞姬、鬼谷子、张良、少司缘；装备先给虞姬，组件各一张后升4级找大司命。
- 8—11回合：升5级补敖隐、东皇太一，输出装备移给敖隐。
- 12回合后：觉醒核心；有空位时补太乙真人或瑶。

站位：以英雄和图腾围住敖隐，减少后排被切；东皇太一前排承伤。

调整：决赛可把张良换成太乙真人保护敖隐；瑶可携带控制装备补容错。

装备方向：敖隐可选寒霜侵袭、破晓、自然法杖；东皇太一可选霸者重铠、近卫荣耀、不死鸟之眼。

天赋条件：复印机：获得两张天赋牌复印机，可指定1—3阶英雄获得其英雄牌。；大河新援：获得2能量和随机一张2—3阶大河流域英雄牌。

## 河洛古币流

成型英雄：百里玄策、上官婉儿、盾山、程咬金、钟馗、太乙真人、李元芳。

古币产出集中养百里玄策，玄策整备根据上一回合闪现英雄击败数成长；钟馗削减击败者临时等级，太乙真人提供复生。

棋手选择：姜导、常小娥、闹闹。天赋方向：瞬影连斩、微弱优势。

- 1—3回合：李元芳或弈星开局，第2回合升2级找玄策；可拿盾山，古币给玄策。
- 4—7回合：升3级，优先觉醒玄策，补程咬金、钟馗。
- 8—11回合：升4级找上官婉儿、太乙真人，11回合前升5级；继续觉醒已有组件。
- 12回合后：补玄策装备与觉醒；战力不足可评估等级转移或五阶转型。遗志接收者随机；化铁为金随机变为未在场五阶，不能指定李信或花木兰。

站位：李元芳、太乙真人靠近玄策，确保最近目标正确；按敌方主输出位置调整玄策。

调整：遗志不转移临时等级；化铁为金限1—3阶目标，转为随机未在场五阶英雄，觉醒并保留当前等级（包括临时等级）。李信为4阶，不能通过化铁为金获得。

装备方向：百里玄策可选无尽巨剑、炽热支配者、影牙；程咬金可选聚灵水晶、不死鸟之眼、不祥征兆。

天赋条件：瞬影连斩：闪现英雄击败敌方单位时，立即闪现至最近敌人处，并无敌0.5秒。；微弱优势：打出觉醒英雄牌时，该英雄增加22%暴击率和11%物理、法术吸血，每名英雄仅一次。

## 逐鹿战术牌流

成型英雄：蒙犽、芈月、西施、白起、老夫子、庄周、鲁班七号。

各组件产出战术牌，使用效果牌时由芈月给装备最多的逐鹿英雄加等级。蒙犽必须保持该目标身份。

棋手选择：白歌、小妲己、闹闹。天赋方向：春风化雨、令行如流。

- 1—3回合：弈星过渡，第2回合升2级找芈月。
- 4—7回合：升3级补西施、老夫子、白起，优先觉醒芈月后升4级；缺觉醒也应继续推进。
- 8—11回合：升5级补蒙犽、庄周、鲁班七号；觉醒优先芈月、西施、白起，再完善输出。
- 12回合后：继续找蒙犽、鲁班七号；空位补太乙真人或海月。

站位：蒙犽后排、白起前排；确保蒙犽装备件数严格多于其他逐鹿英雄。

调整：无空位又需复生时，可用太乙真人替换老夫子。闹闹适配以开局选到逐鹿为条件。

装备方向：蒙犽可选无尽巨剑、炽热支配者、法源之杯；白起可选霸者重铠、不死鸟之眼、不祥征兆。

天赋条件：春风化雨：回合开始获得一张上阵逐鹿英雄的同名牌；上一轮获胜时改为两张。；令行如流：获得一张战术牌，此后每个回合开始再获一张；棋手达到5级后必定为高阶战术。

## 共同条件

- 闹闹需要实际选到对应阵营。
- 常小娥秘技建议场上达到四名英雄后使用。
- 蔡文姬响应使用三分英雄牌，小乔响应登场，触发事件不同。
- 微弱优势在打出觉醒英雄牌时对该英雄生效，每名英雄一次。
- 姜导每打出两张英雄或效果牌触发一次等级成长，每回合最多五次。
- 复印机仅复制1—3阶英雄。
- 智能装甲要求实际穿戴日落海专属装备。
- 令行如流在回合开始继续提供战术牌，棋手五级后才保证高阶战术。
- 红魔要求附近无友军，应与围护输出的站位选择一起考虑。

替代、保护输出与转养建议需要根据对手和资源判断；没有收录无条件克制关系。
