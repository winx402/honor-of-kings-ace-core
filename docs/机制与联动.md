# 机制与联动

适用玩法：万象大赛基础内容，具体平衡版本未指定。关键词规定触发条件，不能单独决定多效果的优先级。

## 主要触发窗口

| 关键词 | 触发条件 |
| --- | --- |
| 整备 | 回合开始 |
| 开团 | 战斗开始 |
| 登场 | 使用对应卡牌后 |
| 合成 | 使用已在场同名英雄牌，结合并强化 |
| 凯旋 | 英雄上阵期间，本轮战斗胜利 |
| 败阵 | 英雄上阵期间，本轮战斗失败 |
| 退场 | 场上英雄被出售 |
| 牺牲 | 英雄阵亡 |

主动让英雄触发一次登场效果，与使用一张英雄牌并不相同。例如曹操整备可重新触发三分英雄的登场，小乔响应登场效果；蔡文姬的条件则是使用三分英雄牌，不能据此自动多算一次。

## 成长与特殊单位

临时等级在战斗结束时清除，不能直接写入永久成长。夺取从周围一格内随机己方英雄取得最多十级，不包含临时等级。

阿科米亚核心在开团时把等级平均分配为己方日落海英雄的临时等级，单英雄分配量不超过核心等级的一半。图腾是大河流域相关特殊单位，存活时提供自身效果；特殊单位不自动视为英雄牌。

复生的基础语义是阵亡后回到战斗并恢复一半生命，一名英雄单回合最多十次；具体英雄技能可以指定不同恢复量或条件。完美复生的细节不能直接套用普通复生。

闪现在开战时跳到敌方战场的镜像位置；落点被占用时的处理未知。

## 常见联动的实际条件

- **整备与核心**：朵莉亚响应英雄整备，增加英雄与核心等级；海诺响应核心升级。没有明确自触发规则时，不把海诺额外等级算成无限循环。
- **开团与整备**：雅典娜开团重新触发日落海英雄整备，进而衔接朵莉亚等监听效果。
- **图腾与敖隐**：每个图腾按四秒周期给敖隐攻速和临时等级；虞姬按图腾数提供等级，张良响应开团提供永久等级。
- **效果牌与芈月**：使用效果牌后，装备最多的一名己方逐鹿英雄增加等级。要养蒙犽，就需要使其满足装备目标条件。
- **复生与站位**：太乙真人把复生给最近英雄；主输出离得近才可能获得目标效果，不能只按阵容名单判断保护成立。
- **牺牲与降级**：钟馗给自身及左右一格英雄赋予削减击败者临时等级的牺牲效果，带单场次数限制。

这些条件描述联动是否成立，不表示阵容一定获胜。详细条目见[关键词](../entities/keywords/catalog.json)、[事件](../rules/mechanics/events.json)和[联动](../rules/mechanics/interactions.json)。

## 伤害量示例

苏烈1级物攻为32，基础技能的标称伤害为`80 + 0.8 × 物攻`，代入得105.6；10级节点把攻击系数提高为1.2。这里没有把105.6当作目标最终掉血：目标防御、额外增伤、免伤与取整还会影响最终结果。

英雄等级、装备面板、技能条件与目标状态都应分别计算。全局防御、回蓝和攻速公式未指定，不能据此计算完整战斗结果。

状态、单位和形态另见[状态与特殊单位](状态与特殊单位.md)。
