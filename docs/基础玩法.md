# 万象大赛基础玩法

适用玩法：万象大赛。具体平衡版本未指定；以下数值不替代其他模式的独立规则。

## 一局如何进行

六名棋手同局，每人从60点生命开始。通过购买卡牌、培养英雄和安排阵容逐回合战斗。每回合匹配一位对手；败者扣除棋手生命，生命耗尽后淘汰，最后存活者获胜。

英雄自动进行战斗。棋手等级影响天赋、高阶英雄牌机会及部分上阵人数节点；英雄等级决定单位自身成长，两种等级分开。

## 购牌、上阵与成长

英雄牌常规购买价格是3能量，品阶不等于价格。将牌拖到战场，没有同名英雄时生成单位，已有同名英雄时合成并增加等级。常规英雄从1级开始，上限999。

觉醒状态、英雄等级、临时等级和棋手等级是不同维度。英雄的等级强化节点也不是觉醒：苏烈的卡面觉醒把牺牲成长由2级变为4级，其战斗技能则另有10、40、100级节点。

出售手里的英雄牌或已上阵英雄，常规各得1能量。出售上阵英雄还可能触发退场；出售不是阵亡，不应自动触发牺牲。

## 能量与天赋

回合给予能量，剩余能量可累积。购牌、棋手升级和部分技能消费能量；天赋、效果牌等也可能提供能量。各效果的消费和回报以具体内容为准。

棋手升级时，免费从三个天赋候选中选择一个。天赋有铜、银、金三阶；同场玩家在相同棋手等级获得相同天赋品阶。达到白银段位后，一局有一次天赋刷新机会。棋手6级可以领取专属天赋。

棋手能量与参战单位施法所需法力是不同资源。英雄面板中的技能能量不能当作棋手购牌余额。

## 竞拍

共同竞拍发生在固定节点，拍品包括英雄牌和效果牌。最高报价竞得；同价时较早报价者竞得。未竞得拍品的出价不扣购买能量。

有效报价进入分红池，竞拍结束后向玩家分配；低生命棋手的分配比例更高。具体回合序列、分红权重与取整仍未确定，不能用其他自走棋的金币利息替代。

## 随机与规则边界

商店选中某品阶与选中某个英雄是两层问题。指定英雄概率取决于候选和牌库状态，不能直接把品阶概率当成其命中率。

本版未给出完整商店概率、公共池库存、升级费用、人数容量或战败扣血表；平局、同时淘汰和竞拍有效报价的精确处理也为未知。未知数值不参与确定性计算。
