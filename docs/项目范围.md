# 项目范围与验收

## 定位

核心内容库是本项目的主体，包括基础游戏规则、实体对象、对象关系、机制、具体游戏模式，以及阵容搭配和常见打法知识。规则、建议和统计评价分开维护，并保留版本与来源。网站仅为未来可能的表现形式，当前不实施；未来是否拆分网站或其他应用由用户另行决定。

项目已创建独立目录及开源仓库。当前任务依据官方规则资料和候选资料理解游戏，定义模块、对象关系与关键状态转换；不实施全量采集、战斗引擎或网站。正式数据 Schema 与游戏机制实验尚未完成。

## 内容维护原则

1. 规则和实体记录明确适用的游戏版本、地区、服务器或模式；未知项显式标注未知。
2. 对象关系使用可定位的对象标识，记录条件、适用范围与来源；具体关系类型后续依据内容建模。
3. 来源至少记录原始出处、采集时间与版本信息。官方文字、社区记录、推断和实验观察分别标注。
4. 文字核对与机制实测使用独立验证状态；读到技能说明不代表实际触发、数值或结算顺序已验证。
5. 候选资料未经核验不直接发布为当前规则；公开复用之前确认许可范围。

## 完整性验收

后续完整性报告应给出适用版本、总目录的来源与统计口径、各类别预期数量、已收录数量、字段核对数量、机制实测数量以及缺失和冲突项。无法确定总量时，覆盖率写为未知，不能用已收录数量当作全量。

初始化、定义与内容验收分开：当前验证模块职责、依赖、关系类型、转换、来源及未知项是否清楚；规则数据、实际关系断言、机制行为和完整性仍需后续核验。
