# 知识范围

本仓库保存《王者万象棋》的知识结果，包括基础规则、实体、关系、机制、具体模式、阵容搭配和常见打法。规则、建议及统计评价分别表达。

研究过程、来源与依据、实验记录、会话记录和生产工具不属于仓库内容。网站或其他应用另行划分。

## 知识表达

1. 每条规则、实体和阵容明确适用版本、地区、环境或模式；未知范围不默认当前。
2. 对象关系使用稳定标识，保留条件、修订和必要参数。
3. 数值与公式标明单位、目标、持续期、上限和作用范围；未知项不补造默认值。
4. 静态定义、局内实例和战斗状态分开；游戏状态的时间、位置及继承关系属于知识语义。
5. 阵容建议标明适用条件；统计结果标明人群、时间窗、样本量和指标口径。

目录和类型定义不代表具体游戏内容齐全。本仓库的知识模型见[模块与关系](模块与关系.md)。
