# 项目范围与验收

## 定位

核心内容库是本项目的主体，包括基础游戏规则、实体对象、对象关系、机制及其版本变化。网站仅为未来可能的表现形式，当前不实施；未来是否拆分网站或其他应用由用户另行决定。

本次范围是创建独立本地目录及公开开源仓库，建立说明、内容目录与维护约定，并迁入既有本地候选资料。本次不进行全量采集、游戏实测或正式数据模型实现。

## 内容维护原则

1. 规则和实体记录明确适用的游戏版本、地区、服务器或模式；未知项显式标注未知。
2. 对象关系使用可定位的对象标识，记录条件、适用范围与来源；具体关系类型后续依据内容建模。
3. 来源至少记录原始出处、采集时间与版本信息。官方文字、社区记录、推断和实验观察分别标注。
4. 文字核对与机制实测使用独立验证状态；读到技能说明不代表实际触发、数值或结算顺序已验证。
5. 候选资料未经核验不直接发布为当前规则；公开复用之前确认许可范围。

## 完整性验收

后续完整性报告应给出适用版本、总目录的来源与统计口径、各类别预期数量、已收录数量、字段核对数量、机制实测数量以及缺失和冲突项。无法确定总量时，覆盖率写为未知，不能用已收录数量当作全量。

项目初始化与内容验收分开：本次仅验收目录隔离、文档定位、许可、公开文件边界及远程同步。规则、实体、关系和机制仍待后续建设。
