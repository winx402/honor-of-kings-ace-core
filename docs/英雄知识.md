# 英雄知识

英雄目录包含85名英雄的阵营、品阶、初始面板、技能名和等级节点。本页展示其中17名的战斗技能，16名同时有卡牌与觉醒效果。初始面板不表示高等级或召唤时的实际面板；具体平衡版本未指定。

## 苏烈

1阶 · 河洛。初始生命330，物攻32，法攻0，物防/法防20/20，攻速0.6次/秒，攻击距离1格，初始法力/上限20/40。

卡牌与觉醒：阵亡触发牺牲时，自身永久等级增加2；觉醒后增加4。

战斗技能：周边物理范围伤害=80+0.8×物攻；削减物防4点，持续5秒。

- 10级：伤害系数提高至1.2×物攻，削减物防改为8点。
- 40级：首次战斗阵亡可复生，恢复至50%最大生命。
- 100级：复生恢复至满生命；周边1格敌人被击飞眩晕1秒并受10%最大生命的物理伤害。
