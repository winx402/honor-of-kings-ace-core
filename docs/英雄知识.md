# 英雄知识

85名英雄的基础与觉醒牌面效果、战斗技能和255个等级节点。初始面板不是高等级实际面板；英雄品阶、等级、觉醒与棋手等级分别计算。平衡版本未统一指定。

## 苏烈

1阶 · 河洛。初始生命330，物攻/法攻32/0，物防/法防20/20，攻速0.6次/秒，距离1格，法力20/40，暴击效果140.0%。

**牌面**：自身阵亡触发牺牲：永久等级增加2。

**觉醒**：牺牲所得永久等级改为4。

**战斗技能**：豪烈万军：旋转攻击周边敌人；每目标物伤80+0.8×物攻，并使其物防降低4点、维持5秒。

- 10级：物伤改为80+1.2×物攻；削减物防改为8点。
- 40级：每场战斗第一次被击败后复生，复生生命为最大生命的50%。
- 100级：复生生命改为最大生命的100%；同时使周围1格敌人击飞眩晕1秒，承受10%最大生命的物伤。该伤害的生命值归属未明。
