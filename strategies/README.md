# 阵容搭配、打法与版本环境

模块标识：`strategy`。维护阵容流派、具体模板、核心/替换位、棋手/装备/天赋/效果牌搭配、运营、站位、转型和有条件的克制关系。

常见/强势评价附适用模式、版本、时间窗、来源与口径；攻略建议和规则事实分开。模式规定的初始阵容由 modes 模块维护，攻略模板只引用相关定义。

站位注明阶段与坐标系，装备建议关联具体阵容位；模板分别记录组件、天赋、运营等缺失项。成型棋盘不等于完整运营攻略，具体契约见[知识站对照](../docs/research/wzwxq对照.md)。

当前完成内容定义，尚未发布完整阵容模板或当前版本热门榜。详见[游戏模式与阵容](../docs/游戏模式与阵容.md)。
