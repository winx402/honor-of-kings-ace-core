# 王者万象棋核心内容

**Honor of Kings: ACE Core** · `honor-of-kings-ace-core`

长期维护《王者万象棋》的基础规则、实体对象、对象关系、游戏模式及阵容打法知识，形成可复用、可追溯、可核验的版本化核心内容库。

这是独立的社区开源项目。网站只是未来的一种表现形式；展示方式及是否另建项目以后再决定。本项目当前专注游戏核心内容。

## 当前状态

已完成项目初始化及0.3版模块、对象关系与关键状态转换定义：11个游戏领域模块、5个支撑模块、69种关系类型与10种转换。正式规则数据、序列化 Schema、自动校验工具和机制实验尚未实现；定义覆盖不代表游戏内容完整。

## 内容范围

- 基础规则：对局流程、资源、成长、胜负条件等。
- 实体对象：英雄、棋手、装备、天赋、效果牌、召唤物、衍生牌等。
- 对象关系：归属、技能关联、生成、强化、触发条件及效果之间的关联。
- 机制：觉醒、等级技能、结算与交互顺序、模式差异和隐藏机制。
- 游戏模式：排位赛、钻石狂潮等玩法/队列、参与条件、专属内容及结算规则。
- 阵容与打法：流派、常见阵容、搭配、运营、站位、替代、克制与版本环境评价。
- 版本与证据：新增、删除、调整、来源、采集时间及字段核验状态。

以上是目标分类，具体实体与关系以资料和验证结果为准。
