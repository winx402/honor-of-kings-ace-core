# 王者万象棋核心内容

**Honor of Kings: ACE Core** · `honor-of-kings-ace-core`

《王者万象棋》的版本化知识结果库，保存规则、实体、关系、模式与阵容理解。网站和CLI各自独立；研究过程、来源、依据与生产工具置于仓库外。

## 阅读知识

- [游戏理解](docs/游戏理解.md)：资源预算、成长、升级、搜索、战斗时序、转型和应对判断。
- [阵容与打法](docs/阵容与打法.md)：18套流派模板，包含获胜方式、成长引擎、组件、运营、装备站位、成型、转型与失败点。
- [基础玩法](docs/基础玩法.md)、[机制与联动](docs/机制与联动.md)。
- [英雄知识](docs/英雄知识.md)：85名英雄的牌面、觉醒、技能和255个节点。
- [棋手能力](docs/棋手能力.md)：20名棋手的主动/被动、初始费用、秘技、专属和分支。
- [装备、天赋与效果牌](docs/装备天赋效果牌.md)、[状态与特殊单位](docs/状态与特殊单位.md)。
- [游戏模式](docs/游戏模式.md)、[排位与赛季](docs/排位与赛季.md)、[规则适用范围](docs/规则适用范围.md)。

## 内容范围

知识版本 **0.2.0**。主目录514张牌全部有效果说明：85英雄、73装备、258天赋、98效果牌；20名棋手与326个衍生内容定义分别展开。衍生定义包含单位载体、条件技能、棋手模块、奖励及选择分支，不等于326张可购买手牌。

英雄技能85项、强化节点255项；12个特殊单位有独立面板与详细能力，另保留瑶妹小鹿和阿科米亚核心定义。打法层包括18套模板、18条资源循环、13条运营理解和4种核心改造变体。

规则按正式服、体验服、研发演示与客户端规则集保存。部分全局数值与当前模式完整规则仍未确定，详见[适用范围](docs/规则适用范围.md)；未确定项不以默认值补造。没有实时热门度、胜率或强度排名。
