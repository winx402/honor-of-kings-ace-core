# 王者万象棋核心内容

**Honor of Kings: ACE Core** · `honor-of-kings-ace-core`

《王者万象棋》的版本化知识结果库，维护基础规则、实体对象、对象关系、游戏模式及阵容打法。

仓库只保存整理后的知识及其结构定义。研究过程、来源目录、依据、实验记录和生产工具置于仓库外。网站及其他展示形式以后另行决定。

## 内容范围

- 基础规则：对局流程、资源、成长和胜负条件。
- 实体对象：英雄、棋手、卡牌、装备、天赋、召唤物及衍生内容。
- 机制与关系：归属、生成、强化、触发、目标、公式、概率和状态变化。
- 游戏模式：玩法、队列、参与条件、专属内容和结算规则。
- 阵容与打法：流派、搭配、运营、站位、替代、克制及版本环境。
- 版本：知识适用的游戏版本、模式及规则变化。

内容模型版本为0.4.0：11个领域模块、3个支撑模块、61种关系类型和10类状态转换。具体游戏内容尚不完整，未知项不作为确定规则。
