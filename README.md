# 王者万象棋核心内容

**Honor of Kings: ACE Core** · `honor-of-kings-ace-core`

《王者万象棋》的版本化知识结果库，维护规则、实体、关系、游戏模式及阵容打法。网站和CLI是独立项目；本仓库只保存知识结果及其结构定义。

## 阅读知识

- [基础玩法](docs/基础玩法.md)：六人对局、能量、购牌、成长、天赋和竞拍。
- [机制与联动](docs/机制与联动.md)：14个关键词、触发窗口和7组联动条件。
- [英雄知识](docs/英雄知识.md)、[棋手能力](docs/棋手能力.md)。
- [装备、天赋与效果牌](docs/装备天赋效果牌.md)。
- [游戏模式](docs/游戏模式.md)：万象大赛、排位赛、钻石狂潮和巅峰试炼。
- [阵容与打法](docs/阵容与打法.md)：五套入门模板，包含运营、站位、替代和搭配条件。

## 首版范围

知识版本为 **0.1.0**。目录包括85名英雄、20名棋手、73件装备、258项天赋、98张效果牌、13个衍生/召唤单位及阿科米亚核心机制对象。

已有136张卡牌的效果概括、17名英雄的战斗技能及51个强化节点、20名棋手的主技能/秘技/专属及28项秘技奖励。英雄目录还包含全部85名的初始面板、技能名和等级节点。目录数量包含仅有属性的条目，不代表所有效果已详述。

具体客户端和平衡版本未指定。378张主目录卡牌尚未详述效果；钻石狂潮、巅峰试炼尚无完整玩法与结算规则。全局防御、回蓝、攻速、商店概率、容量和扣血表也有缺项，不作为确定性计算参数。不提供实时热门度、胜率或强度排名。
